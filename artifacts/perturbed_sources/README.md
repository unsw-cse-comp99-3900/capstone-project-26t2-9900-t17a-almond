# Perturbed Sources

This directory stores source files generated by the active perturbation module.

## Layout

```text
run_YYYYMMDD/
  manifest.csv
  sources/
generated/
```

- `run_YYYYMMDD/` is an archived experiment that may be committed.
- `manifest.csv` records the original file, variant, action, graph-level intent,
  application status, and a reproducible DeepWuKong command.
- `generated/` is the default output for new local runs and is ignored by Git.

The current archived run contains 23 generated variants from 10 original
samples. Original source files remain under `../../input_sources/`.

# Joern CPG Artifacts

This directory stores binary Code Property Graphs generated by Joern for
validation or archived experiments. These files are intermediate artifacts,
not source inputs.

| Path | Contents |
|---|---|
| `cwe119_validation/` | CPGs proving that all ten selected official CWE-119 sources parse successfully. |

New regenerable CPGs should be written to a run-specific generated directory
rather than mixed into `input_sources/`.

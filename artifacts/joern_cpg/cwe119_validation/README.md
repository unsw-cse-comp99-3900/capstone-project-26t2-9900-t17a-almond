# CWE-119 Joern Validation

This directory contains one Joern CPG for each of the ten selected official
DeepWuKong CWE-119 samples. All ten parse operations completed successfully.

`validation.json` preserves the original validation command, runtime, output
size, and log tail for each sample. Paths embedded inside those historical log
tails refer to the machine where validation was performed and are not runtime
paths for this repository.

Current source, XFG, and CPG paths are indexed in
`../../../input_sources/cwe119/metadata.csv`.
